# Examples

Ready-to-copy setups. Each folder is complete: take it, change the files to suit you, and you are done. There is nothing to
create.

| Folder | What it is |
|---|---|
| [`docker/`](docker/) | The SoapCLI web UI in Docker Compose, with example profiles, placeholder options, request files, attachments and a small mock service to try it against. |
| [`workspaces/`](workspaces/) | The same, with **workspaces**: one folder per team, each with its own profiles, placeholder options, attachments, saved requests and secrets, shared by whoever opens the UI. |
